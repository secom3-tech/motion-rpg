    기력이 소진됐어

    S21 연결은 유지돼. 바로 재도전하면 새 연결 코드를 입력할 필요 없어.

    MOTION RPG / v0.47

    실전 모션 전투 설정

    폴드6에서는 3D 전투와 전면 카메라 회피를 사용해. S21은 일반 모드에서 휘두르기·투척, 아령 실험 모드에서 천천히 굽혔다 펴는 한 번의 반복을 공격으로 전송해.

    ① S21 무기 컨트롤러 연결 · 숫자 6자리

    폴드6에서 [연결 코드 만들기] → S21의 Chrome/삼성 인터넷에서 연결 주소 열기 → 같은 6자리 코드로 연결 → S21에서 [센서 켜기]를 눌러. 아령 모드는 아래/위 자세를 2번 보정해야 해. 게임과 컨트롤러는 각각 열린 상태여야 해.

    연결 전
    S21 컨트롤러 화면
    S21 연결 대기 · 무선 통신은 외부 PeerJS 중계 서버를 사용해.
    검격/투척 입력: 없음

    몬스터 발견 시 자동으로 시점이 따라가며, 손으로 시점을 움직이면 잠시 일시 중지돼. S21의 락온 버튼이나 이 설정에서 끌 수 있어.

    ② 폴드6 카메라 회피

    휴대폰을 세로로 고정하고 약 1.5~2.5m 앞에서 상반신과 허리가 모두 보이게 서 있어. 처음 2초는 가만히 서서 기준 자세를 잡고, 좌우로 몸을 피하거나 앉는 동작으로 회피해.

    카메라 연결을 기다리는 중
    카메라 대기 · 기기 밖으로 영상이 전송되지 않아.

    모션 인식이 불안정하면 터치 버튼으로 계속 전투할 수 있어. 폰을 실제로 던지지 말고 주변에 사람·물건이 없는지 확인해. GitHub Pages 외에 무료 WebRTC 연결 서버와 카메라 인식 모델 다운로드가 필요하므로 인터넷 연결이 필요해.
