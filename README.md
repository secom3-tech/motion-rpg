# Motion RPG — 경계의 숲

실행 주소: https://secom3-tech.github.io/motion-rpg/preview.html

**운동을 게임의 목표가 아니라 게임 조작으로 만드는 판타지 RPG.** 숲 입구의 마을을 거점으로 3D 몬스터를 사냥하고, 야외에서는 이어폰과 GPS 페이스로 원정을 진행한다. 같은 캐릭터가 성장한다.

## v0.28 통합 플레이

- 마을: 숲마을 전경과 사냥꾼 캐릭터, 길드 의뢰 게시판, 대장간, 숲길 안내인.
- 실내: WebGL 3D 몬스터 5종(슬라임 3종·그림자 늑대·유적 골렘), 반격 예고, 회피, 플레이어 기력, 장비 효과.
- 대장간: 실제 소유한 장비만 장착. 몬스터 사냥 XP·골드·제작 재료 → 제작 → 전투 능력치 상승. 고급 장비는 레벨/보스 격파 필요.
- 야외: 음성 중심 GPS 모험 및 러닝머신과 책상 시뮬레이션. 책상 모의 플레이와 수동 러닝머신 입력은 실제 보상을 지급하지 않는다.
- 장비 외형 시착은 실제 소유·제작·전투 능력치와 분리돼 있다.

## 조작

- 시점: 드래그 / 마우스.
- 이동: 왼쪽 가상 조이스틱 또는 WASD.
- 근거리 공격: 검격 버튼 또는 F.
- 원거리: 투척 버튼 또는 Space. 사냥활을 장착하면 사냥 화살로 표시된다.
- 회피: 회피 버튼 또는 Q/Shift. 경고 뒤 적절한 타이밍에 대응한다.
- 마을 복귀: 전투 정산. 재료를 받은 뒤 마을의 장비실에서 제작/장착한다.

## 주요 파일

- preview.html — 통합 플레이, 마을·캐릭터·제작·음성 탐험.
- indoor.html — 실내 WebGL 사냥 전투.
- src/gear-game.mjs — 장비 획득·제작·장착·능력치·보상 중복 방지.
- src/avatar.mjs — 사냥꾼 장비 외형 시안.
- src/engine.mjs — 기존 저장·퀘스트·보스 규칙.
- src/expedition.mjs — 음성 러닝 사건과 GPS 시뮬레이션.
- index.html — 기존 실험 허브. 본 게임 기능 보존.
- docs/PRODUCT_VISION.md — 초기 기획 및 변경 불가 핵심 원칙.

## 현 단계에서 미완성

- 마을·캐릭터는 3D풍 캔버스 시안이다. 자유 이동형 진짜 3D 마을 및 실내 캐릭터 모델의 시각적 연동은 미구현.
- 폴드6 카메라의 관절 회피 인식, S21 실제 검격/투척 신호와 3D 전투의 실시간 연결은 미완성.
- GPS/이어폰과 백그라운드 탐험의 실제 기기 시험이 필요하다.
- 저장은 브라우저 localStorage만 사용한다. 계정/서버 저장 및 변조 방지가 없으며, 정식 다중 사용자 경제에 적합하지 않다.
- 테스트는 npm test로 실행한다. 자동 밸런스 검사는 실제 플레이의 재미나 운동 안전성을 입증하지 않는다.

현재 배포는 GitHub Pages만 사용한다. Netlify는 사용하지 않는다.

## v0.29 전투 판정 수정

- 몬스터 출현 좌표가 거의 고정돼 있던 문제 수정: 플레이어 위치·시야를 기준으로 안전거리 약 11~18m 부근의 여러 좌표에서 출현한다. 지도 경계에서는 예외 좌표를 선택한다.
- 플레이어가 몬스터 뒤나 옆에 있을 때 거리만으로 피해를 받던 오류 수정. 각 몬스터의 공격 범위·전방 각도·바라보는 방향을 계산해 피해를 결정한다.
- 몬스터가 몸을 실제로 돌리고, 공격을 예고할 때 방향을 고정한다. 예고 중 측면/뒤로 이동하거나 사거리 밖으로 나가면 공격을 피할 수 있다.
- 피격 시 화면 붉은 충격 효과, 카메라 흔들림, 피해 수치와 기력 표시 효과 추가. 공격 경고도 명시한다.
- 테스트: 5종의 정면·측면·후방 판정과 지도 안 랜덤 출현 3,000회, 전투 JS 구문 검사.

## v0.30 두 휴대폰 모션 전투

**첫 연결 순서 (Galaxy Fold6 화면 + Galaxy S21 무기 컨트롤러)**

1. 폴드6에서 https://secom3-tech.github.io/motion-rpg/indoor.html 을 전체 화면으로 연다.
2. 오른쪽 위 '모션 설정' → '연결 코드 만들기'. 화면에 `mrpg-...` 코드가 뜬다.
3. S21에서 https://secom3-tech.github.io/motion-rpg/controller.html 을 열고 코드를 입력하거나 폴드6의 '연결 주소 복사'를 사용한다. '게임 연결'을 누른다.
4. S21에서 '센서 켜기'를 누른다. 투척/검격 모드를 선택하고 필요하다면 민감도와 회전축을 설정한다. 실제 몸 동작이 폴드6 전투의 투척/검격 공격으로 들어간다.
5. 폴드6에서 '카메라 자세 인식 켜기'를 누르고 정면에서 상반신·골반이 보이도록 1.5~2.5m 앞에 선다. 약 2초 가만히 자세 기준을 잡는다. 가로 공격은 앉기, 내려찍기는 좌우 이동으로 회피한다.
6. 모션 설정 창을 닫고 싸운다. 버튼/키보드 회피, 근접 및 원거리 공격은 계속 사용 가능하다.

**현재 기술적 제약**

- GitHub Pages는 정적 호스팅이라 두 기기의 WebRTC 연결을 처음 맺는 데는 무료 PeerJS Cloud 신호 중계 서비스와 외부 PeerJS CDN을 사용한다. 서버 장애, NAT/방화벽, 네트워크 상태에 따라 연결되지 않을 수 있다. GitHub Pages만으로 P2P 연결을 보장하지는 못한다.
- 폴드6 전면 카메라 자세 인식은 MediaPipe Tasks Vision Pose Landmarker Lite 모델(브라우저 내 연산, 약 8 FPS)을 사용하며 모델과 런타임을 CDN에서 다운로드한다. 영상 프레임은 S21로 보내지 않는다. 느린 기기/어두운 곳/프레임 안에 상반신·골반이 보이지 않을 때는 인식이 실패할 수 있다.
- S21은 자세분류 이벤트(검격/투척, 강도, 시각, 시퀀스)만 전송하며 실제 센서 원본 데이터는 폴드6로 전송하지 않는다. 연결 코드는 임시 코드이며 외부와 공유하지 않는다.
- 실제 폴드6·S21의 카메라 권한/센서 권한/통신 지연/장시간 동작은 아직 **실기기 확인 전**이다. 현재는 프로토타입이며 부정행위 차단·안전성·게임 밸런스를 보증하지 않는다.
- 공간을 비우고 기기를 놓치지 않게 잡는다. 스마트폰을 실제로 던지지 않는다. 불편하면 카메라/센서를 끄고 버튼으로 플레이한다.
- 테스트: `node tests/motion.mjs`, `node tests/network.mjs`를 포함한 `npm test`. 기기 2대의 실제 WebRTC 연결 자체는 자동 테스트 대신 현장 점검이 필요하다.
