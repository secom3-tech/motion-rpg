# Motion RPG

실내 액션 RPG와 야외 **음성 중심 러닝 RPG**를 하나의 캐릭터로 연결하는 운동 게임.

## 바로 실행하기

- **음성 러닝 모험:** [expedition.html](./expedition.html) — 이어폰 + GPS 실전/책상 시뮬레이션, 버튼 조작 없이 달리기 페이스로 사건 해결
- 마을 및 기존 콘텐츠: [index.html](./index.html)
- 실내 1인칭 전투 프로토타입: [indoor.html](./indoor.html)
- S21 모션 센서 컨트롤러: [controller.html](./controller.html)

## 핵심 기획 원칙

운동을 하기 위해 게임을 붙이는 것이 아니라, 게임의 목표를 이루려다 자연스럽게 운동이 되게 만든다. 실내는 스킬과 손동작·몸동작을 활용하는 액션 RPG. 야외는 **오디오로 몰입하는 생존·탐험·인터벌 러닝**. 달리는 동안 화면을 계속 보거나 조작하지 않아야 한다.

작은 세계에서 풍부한 이벤트와 선택·아이템·기술 조합을 제공하며 난이도와 보상의 일관성을 자동 검증한다. 복잡한 서사 확장과 무분별한 지역 추가를 피한다. 안전한 운동 강도와 게임의 도전 난이도를 분리한다.

## 개발

정적 웹 프로젝트. `npm test`를 실행하면 기존 게임 경제·상태 테스트와 러닝 모험 자동 시뮬레이션이 수행된다. GitHub에 push하면 연결된 Netlify 사이트로 자동 배포된다.

상세 기획·구현 기준은 [docs/GAME_RULES.md](./docs/GAME_RULES.md)를 참조한다.

**현재 상태:** GPS 러닝·음성·모션 등은 베타/실험 기능이다. 실기기에서 모든 정확도가 검증된 완제품이 아니다.
