# 게임 설계 기준 (초안)

## 최우선 목표
- 운동 횟수 자체가 아닌 **게임의 도전과 기술 습득**을 재미의 중심에 둔다.
- 실내 액션 RPG와 야외 러닝은 **하나의 캐릭터와 인벤토리**를 공유한다.
- 복잡한 세계관 확장보다 **작은 지역에서 풍부한 사건 조합**을 우선한다.

## 설계상의 불변 조건
1. 경험치, 보상, 레벨, 확률, 난이도 계산은 고정된 게임 엔진이 담당한다. AI는 규칙을 마음대로 바꾸지 않는다.
2. 콘텐츠는 정해진 데이터 규격으로만 추가한다. 이벤트는 실패했을 때도 이야기가 이어지게 한다.
3. 새 콘텐츠마다 회귀 테스트와 경제·보상 통계 검증을 수행한다.
4. 게임 난이도와 실제 운동 강도를 분리한다. 더 어려운 이벤트가 무조건 더 빠른 질주를 요구해서는 안 된다.
5. 러닝 인터벌은 개인별 안전 범위에 맞추며, 차량 통행과 주변 위험을 무시한 가속·방향 전환을 요구하지 않는다.
6. 실내 자세 인식은 카메라, 손동작은 S21 센서, 야외 이동은 GPS를 기본 후보로 삼는다. 아직 통합되지 않았다.
7. 플레이어의 건강 상태를 단순 점수로 확정하지 않고, 페이스와 활동량은 게임 입력으로만 사용한다.

## v0.2 러닝 사건 흐름

한 구간은 `탐험 → 사건 → 대응 선택 → 결과 → 탐험`으로 진행한다.

- 사건: 추격, 흔적 탐색, 보급 발견, 안개 지대 등 12개 사건. 한 번의 12분 탐험에서 모든 사건이 한 번씩 등장한다.
- 대응: 돌파, 안정 이동, 탐색, 회복. 사건마다 가능한 대응만 노출한다.
- 페이스와 대응의 조합으로 성공 여부가 결정되며, 실패해도 최소 경험치를 얻는다.
- 회복은 게임 기력 회복 수단일 뿐 실제 운동을 지시하지 않는다.
- 엔진은 유효하지 않은 상태 전이(사건 중 중복 시작, 사건 없는 해결)를 오류로 막는다.

## v0.3 탐험 가방

- 보급 사건을 성공하면 횃불, 지도 조각, 붕대 중 정해진 물품을 얻는다.
- 횃불은 안개, 지도 조각은 탐색, 붕대는 추격 사건에서만 선택지로 나타나며 사용하면 하나 소모된다.
- 물품 사용은 해당 사건의 성공을 보장하지만, 실제 운동 행동을 지시하지 않는다.

## v0.4 실내 모의훈련

- 실내 모드도 야외 모드와 동일한 캐릭터의 경험치, 골드, 기력, 탐험 가방을 공유한다.
- 방어 리듬, 어두운 훈련장, 회복 루틴이 순환하며, 훈련장에서는 횃불을 사용할 수 있다.
- 현재는 규칙·보상 검증용이며, 카메라·동작 인식·센서 기반 판정은 아직 연결하지 않는다.

## v0.5 캠프 강화

- 골드는 작은 랜턴, 탐험 지도, 훈련 보호대를 구매하는 데 사용한다.
- 강화는 각각 횃불 소모 방지, 탐색 보상 증가, 실내 실패 보상 증가 효과를 가진다.
- 각 강화는 한 번만 구매할 수 있으며, 진행 중인 사건이나 훈련 중에는 구매할 수 없다.

## v0.6 지역 해금

- 경계의 숲 다음 지역으로 달빛 능선을 추가한다.
- 달빛 능선은 레벨 2와 작은 랜턴을 모두 갖추면 이동할 수 있다.
- 지역별 사건 풀과 보상 범위가 다르며, 각 지역의 사건 순환은 별도로 기록한다.

## v0.7 지역 퀘스트와 보스

- 일반 사건의 조사 횟수와 성공 횟수를 채우면 해당 지역의 보스 사건이 열린다.
- 보스 성공 시 지역별 보스 격파가 저장되며, 일반 사건보다 높은 골드 보상을 얻는다.
- 보스 실패 시 격파 상태가 되지 않으며, 준비한 뒤 다시 도전할 수 있다.

## v0.8 운동 입력 어댑터

- 야외는 거리와 시간의 모의 신호로 페이스를 계산해 다음 사건에 사용한다.
- 실내는 동작 수 모의 신호를 받아 훈련 성공 시 소량의 경험치 보너스를 준다.
- 현재 입력은 테스트용 수동 신호이며, 추후 GPS·카메라·웨어러블 데이터로 동일한 어댑터를 교체한다.

## v0.9 실내 러닝머신

- 러닝머신 모드는 속도를 한 번 설정하면 누적 거리와 페이스를 자동 계산한다.
- 테스트용 1분 반영은 추후 앱 타이머 또는 블루투스 러닝머신 데이터로 대체할 수 있다.
- 러닝머신에서 얻은 페이스는 야외와 같은 사건·퀘스트·보상 규칙에 적용된다.

## v0.10 모바일 화면 분리

- 대시보드, 러닝, 실내 화면을 분리해 운동 중 필요한 조작만 보이게 한다.
- 세 화면은 하나의 저장된 캐릭터 상태를 공유한다.

## v0.11 러닝머신 자동 타이머

- 러닝머신 시작 중에는 설정한 속도를 기준으로 거리와 시간이 1초 단위로 자동 누적된다.
- 종료·초기화 시 타이머도 함께 중단되며, 저장된 주행 중 상태를 다시 열면 타이머를 재개한다.

## v0.12 거리 기반 자동 사건

- 러닝머신 누적 250m마다 야외 사건이 자동으로 열린다.
- 사건이 열리면 러닝 화면으로 이동해 선택지를 보여 주며, 처리 중 지나간 거리는 다음 250m 구간부터 다시 계산한다.

## v0.13 탐험 기록

- 최근 해결한 6개의 사건을 성공 여부, 선택, 입력 방식, 보상과 함께 대시보드에서 확인한다.
- 기록은 캐릭터 저장 데이터에 포함되어 새로 열어도 이어진다.

## v0.14 러닝 세션 목표와 종료 리포트

- 러닝머신 시작 전 500m·1,000m·2,000m 목표를 고른다.
- 한 세션의 거리·시간·해결 사건을 종료 화면에 요약하고, 목표 완주 보상은 세션당 한 번만 준다.
- 목표 보상은 사건 보상보다 작게 두어, 반복 클릭이 아니라 실제 누적 주행이 중심이 되게 한다.
- 시작 전 6·8·10·12km/h 프리셋을 고르며, 주행 중에는 기존 ±0.5km/h 조정으로 미세 변경한다.

## v0.15 실제 GPS 야외 러닝

- 브라우저 위치 권한을 허용하면 GPS 좌표 간 거리·시간·페이스를 자동으로 기록한다.
- GPS 누적 250m마다 기존 야외 사건 규칙을 호출하며, 러닝 종료 후 거리·시간·해결 사건을 남긴다.
- 정확도 100m 초과 신호와 8m/s 초과의 비정상 위치 점프는 기록에서 제외한다.
- GPS 권한을 허용하지 않거나 신호가 불안정할 때는 기존 모의 입력이 그대로 남는다.

## v0.16 야외 동반 모드

- GPS 러닝과 러닝머신을 시작하면 화면이 꺼지지 않도록 브라우저에 요청하고, 앱으로 돌아오면 다시 요청한다.
- 음성 안내를 직접 켜면 GPS 시작·종료와 250m 자동 사건을 한국어 음성으로 알린다.
- 홈 화면에 설치 가능한 PWA 메타데이터와 오프라인 기본 자산 캐시를 추가했다.
- 화면을 완전히 끈 상태의 GPS 기록은 모바일 운영체제·브라우저 정책에 따라 제한될 수 있으므로, 실제 운동 기록의 완전성은 아직 보장하지 않는다.

## v0.17 GPS 기록 안정화

- 러닝 중 일시정지·재개를 제공하며, 재개 시에는 새 위치를 기준점으로 잡아 멈춘 시간과 이동이 기록에 섞이지 않게 한다.
- 20초 이상 GPS 신호가 들어오지 않으면 상태를 알리고, 2분을 넘긴 신호 공백 뒤에는 새 기준점부터 기록한다.
- 최근 GPS 구간 최대 5개의 중앙 페이스를 사용해 짧은 위치 오차가 사건 난이도에 바로 반영되지 않게 한다.

## v0.18 원정 UI

- 모바일에서 빠르게 상태를 읽을 수 있는 모험가 HUD, 원정 보드, 야외 원정·실내 던전 화면으로 UI를 재구성했다.
- 야외와 실내의 마지막 세션·진행 중 상태·다음 게임 관문을 캠프 화면에서 한 번에 확인한다.
- 기존 상태 전이와 보상 규칙은 변경하지 않고, 현재의 실내 러닝머신·훈련장 흐름을 게임 화면 안에서 더 분명하게 표현한다.

## v0.19 실내 훈련 던전

- 실내 훈련은 1·3·5회 목표의 짧은 던전 세션으로 시작하며, 각 훈련의 기존 보상과 별도로 세션 완주 보상을 한 번 지급한다.
- 훈련 중 목표를 바꾸지 못하게 하고, 새로 열어도 진행 중 세션은 자동으로 재개하지 않아 의도하지 않은 상태 전이를 막는다.

## v0.20 실내 몬스터 전투

- 실내는 탐험이 아니라 몬스터와 전투하는 던전으로 구분한다.
- 슬라임 사수·그림자 늑대·철갑 골렘이 순서대로 등장하고, 각각 투척·회피·가드 중심의 전투 선택지를 가진다.
- 현재는 버튼으로 전투 판정을 검증하며, 이후 같은 선택지를 카메라·센서 동작 입력으로 교체한다.

## v0.21 턴제 실내 전투

- 실내 몬스터는 각자 HP와 공격력을 가지며, 한 번의 선택으로 끝나지 않고 여러 턴에 걸쳐 처치한다.
- 투척·회피·가드는 몬스터별 핵심 행동이며, 잘못된 선택은 피해는 적지만 전투가 길어진다.

## v0.22~23 기기 분리 모션 입력

- S21은 손에 들고 쓰는 모션 컨트롤러다. 투척과 근접 무기 휘두르기는 자이로·가속도 센서로 감지한다.
- 폴드6은 거치한 게임 화면이며, 카메라는 회피 동작 인식에만 쓴다. 카메라 영상은 브라우저 안에서만 처리한다.
- 현재 S21 컨트롤러는 센서 감지와 임계값 검증 단계다. 폴드6 게임 화면으로의 실시간 전송은 별도의 기기 연결 단계에서 추가한다.
- S21 컨트롤러는 민감도를 5단계로 저장하며, 초기 값은 작은 흔들림 오인식을 줄이기 위해 `조금 낮음`이다.
- 현재는 회전량 전체를 써서 큰 동작을 잡는다. 투척 방향 이외의 각도 변화 오인식을 줄이기 위해, 다음 단계에서는 기준 자세 캘리브레이션과 방향 축 판정을 추가한다.

## 자동 검증

- 상태 전이: 시작 전 보상 없음, 사건 중 중복 시작 불가, 해결 뒤에만 결과 반영.
- 경제: 1,000개의 20분 모의 플레이에서 기력 범위, 보상 상한, 성공률, 경험치 범위를 확인.
- 이 테스트는 게임 재미, 인터벌 안전성 또는 실제 플레이의 밸런스를 입증하지 않는다.

## v0.25 야외 '음성 중심 러닝 RPG' — 원래 기획으로 복귀 (중요)

**야외 러닝은 화면을 보고 선택하는 버튼형 게임이 아니다.** 모험을 시작하면 이어폰의 음성이 사건과 대응 목표를 알려주고, 사용자가 실제 달리기 페이스를 바꾸는 것으로 사건이 진행·판정되어야 한다. 안전한 장소가 아니라면 가속을 요구하지 않고 일시정지 가능해야 한다.

- 별도 화면: `expedition.html`. 기존 수동 사건 선택 UI를 유지하면서 음성 중심 모드를 추가.
- 기본 흐름: 숲 탐험 → 무작위 사건 → 페이스로 대응하는 35~50초 구간 → 성공/실패 음성 안내 → 회복 → 다음 탐험. 화면 조작 없이 한 판 진행.
- 18가지 고유 사건 × 6가지 환경 변화 × 3가지 전투 성향. 최근 4개 사건 중복 방지.
- 사건 종류: 조금 빠르게 달리는 추격(surge), 페이스를 낮추는 은신(quiet), 편안한 페이스 유지(steady).
- 기준 페이스는 사용자가 직접 설정한다. 난이도를 높인다고 무조건 더 빠른 전력질주를 요구하지 않는다.
- GPS 연결 실전 모드와 12배속/4배속 책상 데모는 **동일한 게임 규칙** 사용. 데모는 캐릭터 보상을 절대 지급하지 않음.
- 실제 GPS 세션은 최소 3분, 유효 이동 200m 이상 및 원정 종료 후에만 기존 마을 캐릭터에 XP/골드/아이템 반영. 세션 ID 재사용 시 중복 지급 불가.
- 실제 음성 출력/위치 수신/절전 처리 및 움직임 인식 정확성은 폴드6 실기기에서 추가 테스트가 필요함. GPS 오차가 남아 있는 베타 버전.
- 자동 테스트: 독립적인 20분 러닝 1,000회 시뮬레이션, 사건 다양성, 보상·상태 불변성, 데모 보상 차단, 중복 지급 방지 확인.
- 실내 체감형 전투는 폴드6 카메라 + S21 모션 센서로 계속 개발하지만, 야외 러닝을 실내 전투식 버튼 조작 게임으로 혼동하지 말 것.

## v0.28 통합 사냥 · 제작 · 성장

- 전투 결과의 XP/골드/제작 재료는 동일 세션당 한 번 정산한다.

- 장비는 소유 후 제작 비용 지불/장착 규칙을 통과해야 실제 전투 수치에 영향을 준다.

- 실제 GPS 승인 원정에 제작 재료를 추가하고 데모/수동 러닝머신 모드에는 지급하지 않는다.
- 자동 시뮬레이션으로 제작·보상·상태를 검사하지만 신체 동작 판정과 재미/안전은 실기기 확인 전이다.

## v0.30 모션 전투 입력 규칙

- S21은 실제 IMU 동작을 재준비/쿨다운 후 분류해 검격과 투척을 전송한다. 신뢰하는 장치 1대만 게임에 연결된다.

- 가로 공격: 몸 낮추기, 내려찍기: 좌우 이동. 버튼 회피는 모든 패턴에 대응할 수 있는 디버그/접근성 조작이다.
- 공격 가능/쿨다운, 몬스터 정면·거리 판정은 기존 게임 엔진의 조건을 그대로 따른다.
- 무선 실전에서 다른 장치의 입력을 완전히 인증하는 시스템은 아니며 시뮬레이션 버튼은 공격 보상으로 처리하지 않는다.
- 모션 카메라나 무선 연결이 작동하지 않을 경우 기존 버튼/키보드 입력을 사용한다.

## v0.32 전투 가시성 규칙

- 모든 근접 공격은 준비 동작, 타격, 짧은 후속 움직임 단계를 가진다.
- 바닥 표식의 전방 범위는 실제 맞을 수 있는 충돌 범위와 동일하게 계산한다.
- 공격 예고부터 타격까지 방향을 고정하여 뒤·측면 회피가 가능해야 한다.
- 가로 공격은 앉기, 내려찍기는 좌우 회피로 대응하며 버튼 회피는 대체 입력으로 남긴다.
- 공격이 빗나가더라도 휘두르거나 내려찍는 공격 궤적은 실제로 보여야 한다.

## v0.33 플레이어 무기 공격 규칙

- 5종 무기는 각각 근접 사거리, 공격 프레임, 원거리 발사체 외형과 공격 배율이 다르다.
- 가로 베기는 넓은 전방 각도, 내려찍기는 보통 전방 각도, 찌르기는 좁은 전방 각도의 실제 충돌 판정을 가진다.
- 근접 피격 판정은 공격 시작 시가 아닌 휘두르는 동작의 접촉 프레임에서 검사하며 뒤에 있는 적에게 피해를 주지 않는다.
- 기본 활 근접은 활로 밀치기이며 검격처럼 강한 근접 피해를 주지 않는다.
- 활은 화살, 지팡이는 정령구, 그 외 무기는 각자 다른 성격의 마력/원소 투사체를 발사한다.
- 터치 버튼은 드래그 방향으로 공격 스타일을 선택하며, S21은 인식된 방향 또는 사용자가 고정한 스타일을 전송한다.
- 무선 입력·실전 보상과 기존 시착/실전 장비 저장 분리를 유지한다.

## v0.34 투척 사이클 / 근접 전환

- 투척 최소 감지 간격 1.9초, 유효한 정지 구간 0.75초가 지나야 새로운 공격을 감지한다.
- 자동 모드에서 앞으로 뻗는 동작은 원거리, 좌우/세로 휘두르기는 근접으로 전달한다. 근접 방향은 동작창 또는 사용자 학습값으로 판정한다.
- 자동 인식이 불안정하면 투척 고정/근접 고정 및 가로/세로/찌르기 고정 옵션을 사용할 수 있다.
- 활은 화살 사격을 주 공격으로 사용하고 근접 행동은 검기 없는 약한 밀치기를 사용한다.
- 실기기에서 한 동작당 한 공격이 되는지 확인하기 전까지 자동 모드는 시험 기능이다.

- 구형 저장본은 다음 레벨 남은 XP를 이월할 때 기존 100 XP 레벨 구간에서 쌓아둔 비율을 반영한다.

- 늑대/멧돼지는 역동적인 좌우 움직임, 도깨비불은 선회와 거리 유지, 골렘/고목은 묵직하고 가끔 멈추는 움직임으로 구분한다.

- 몬스터의 자세/이동 애니메이션은 실제 몬스터 이동속도와 연동한다. 공격 예고 중에는 움직임을 멈춘다.

## v0.38 골렘 투석·도깨비불 청염탄

- 골렘은 원거리 인식 거리까지 접근한 뒤 몸을 돌려 돌을 들어올리는 준비 모션을 약 2.3초 보여주고, 이후 충돌 가능한 투사체를 발사한다. 도깨비불도 별도 청염탄을 모아 발사한다.
- 투사체의 발사 위치·발사 당시 플레이어 좌표·비행 속도와 반경은 별도 원거리 전투 모듈에 기록하고, 타격은 비행 경로와 플레이어 위치의 실제 교차에서 판단한다.
- 투사체는 발사 뒤 새로운 플레이어 위치를 다시 추적하지 않는다. 걸어서 벗어나거나 적시에 좌우 회피하는 전투가 가능하다.
- 기존 근접 가로 공격/내려찍기/돌진 판정은 그대로 두고, 원거리 공격 종류는 별도 처리해 충돌 판정을 중복 적용하지 않는다.
- 개발 테스트 UI를 숨겨도 GPS/러닝머신의 기존 상태 및 저장 데이터를 변경하지 않는다.

## v0.39 이동형 마을 조작

- 플레이어 좌표는 마을 내 경계에 제한되고 카메라가 부드럽게 따라간다. 이동 방향 입력에 따라 자동 이동은 즉시 취소된다.
- 건물 위 명칭 또는 NPC 시설을 탭하면 해당 장소까지 자동으로 걸어가며, 일정 거리 내 도달 시 한 번만 대화/전환을 일으킨다.
- 빈 마을 바닥을 탭하면 원근 좌표를 역변환해 해당 위치로 이동한다. 바깥 하늘 탭 등은 무시한다.
- 장착한 외형을 마을 아바타에도 렌더링한다. 포인트 장면과 NPC 대화 UI는 직접 선택했을 때만 열린다.
- 기존 게임 저장/미션/보상은 변경하지 않고, 폴드6 전투/야외 GPS/러닝머신 경로를 유지한다.

## v0.40 고정 마을 허브 / 장비 아트 규칙

- 마을은 이동 입력을 받지 않는다. 건물과 목적지 버튼을 누르면 바로 해당 화면/패널로 넘어간다. 마을에서의 가상 조이스틱·카메라 추적·매 프레임 풍경 렌더는 비활성화한다.
- 길드 의뢰 패널은 기존 저장된 지역 퀘스트 진행도를 읽기만 한다. 숲 사냥/야외 원정 보상 조건과 재료·골드·경험치 저장 키를 바꾸지 않는다.
- 대장간은 현재 장비/제작 화면에 연결하고, 시장은 완성 전 거래·보상을 지급하는 것처럼 보이지 않게 한다.
- 장비 시착과 레이어 일러스트 변경만으로 전투 능력치나 소유 장비를 변경하지 않는다. 실제 제작/장착 시에만 기존 `gear-game.mjs` 규칙을 사용한다.
- 신규 화면을 테스트하면서 고정 마을 정적 이미지/시설/장비 일러스트의 연결을 회귀 검증한다.

## v0.41 근접·원거리 2슬롯과 명확한 전투 피드백

- 시작 무기: 초보자의 검(근접 슬롯) + 허름한 활(원거리 슬롯). 전투는 마을에서 준비한 두 무기를 그대로 가져간다. 외형 시착 전용 저장키를 더 이상 사용하지 않는다.
- S21 패드 무기 전환 버튼을 기본값으로 사용한다. 자동 모션 전환은 선택적으로만 켤 수 있으며, 신뢰도는 실기기로 검증해야 한다.
- 활이 선택되면 근접 공격을 사용할 수 없다. 검 선택 시 원거리 발사는 사용할 수 없다. 각 장착 슬롯마다 보유 중인 아이템만 선택할 수 있다.
- 회피는 "동작 인식됨"과 "공격을 실제로 피함"을 분리해서 표시한다. 성공한 회피만 성공 피드백을 준다. 피격은 피해 수치/진동으로 구분한다.
- 원정은 시간 지정 없이 자유 탐험을 시작할 수 있으며 최대 2시간 안전상한을 둔다. 실측 GPS 페이스로 보정하고, 실내 수동 입력 원정은 실전 보상이 없다.
