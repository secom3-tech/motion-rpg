# 게임 설계 기준 (초안)

## 최우선 목표
- 운동 횟수 자체가 아닌 **게임의 도전과 기술 습득**을 재미의 중심에 둔다.
- 실내 액션 RPG와 야외 러닝은 **하나의 캐릭터와 인벤토리**를 공유한다.
- 복잡한 세계관 확장보다 **작은 지역에서 풍부한 사건 조합**을 우선한다.

## 설계상의 불변 조건
1. 경험치, 보상, 레벨, 확률, 난이도 계산은 고정된 게임 엔진이 담당한다. AI는 규칙을 마음대로 바꾸지 않는다.
2. 콘텐츠는 정해진 데이터 규격으로만 추가한다. 이벤트는 실패했을 때도 이야기가 이어지게 한다.
3. 새 콘텐츠마다 회귀 테스트와 경제·보상 통계 검증을 수행한다.
4. 게임 난이도와 실제 운동 강도를 분리한다. 더 어려운 이벤트가 무조건 더 빠른 질주를 요구해서는 안 된다.
5. 러닝 인터벌은 개인별 안전 범위에 맞추며, 차량 통행과 주변 위험을 무시한 가속·방향 전환을 요구하지 않는다.
6. 실내 자세 인식은 카메라, 손동작은 S21 센서, 야외 이동은 GPS를 기본 후보로 삼는다. 아직 통합되지 않았다.
7. 플레이어의 건강 상태를 단순 점수로 확정하지 않고, 페이스와 활동량은 게임 입력으로만 사용한다.

## v0.2 러닝 사건 흐름

한 구간은 `탐험 → 사건 → 대응 선택 → 결과 → 탐험`으로 진행한다.

- 사건: 추격, 흔적 탐색, 보급 발견, 안개 지대 등 12개 사건. 한 번의 12분 탐험에서 모든 사건이 한 번씩 등장한다.
- 대응: 돌파, 안정 이동, 탐색, 회복. 사건마다 가능한 대응만 노출한다.
- 페이스와 대응의 조합으로 성공 여부가 결정되며, 실패해도 최소 경험치를 얻는다.
- 회복은 게임 기력 회복 수단일 뿐 실제 운동을 지시하지 않는다.
- 엔진은 유효하지 않은 상태 전이(사건 중 중복 시작, 사건 없는 해결)를 오류로 막는다.

## v0.3 탐험 가방

- 보급 사건을 성공하면 횃불, 지도 조각, 붕대 중 정해진 물품을 얻는다.
- 횃불은 안개, 지도 조각은 탐색, 붕대는 추격 사건에서만 선택지로 나타나며 사용하면 하나 소모된다.
- 물품 사용은 해당 사건의 성공을 보장하지만, 실제 운동 행동을 지시하지 않는다.

## v0.4 실내 모의훈련

- 실내 모드도 야외 모드와 동일한 캐릭터의 경험치, 골드, 기력, 탐험 가방을 공유한다.
- 방어 리듬, 어두운 훈련장, 회복 루틴이 순환하며, 훈련장에서는 횃불을 사용할 수 있다.
- 현재는 규칙·보상 검증용이며, 카메라·동작 인식·센서 기반 판정은 아직 연결하지 않는다.

## v0.5 캠프 강화

- 골드는 작은 랜턴, 탐험 지도, 훈련 보호대를 구매하는 데 사용한다.
- 강화는 각각 횃불 소모 방지, 탐색 보상 증가, 실내 실패 보상 증가 효과를 가진다.
- 각 강화는 한 번만 구매할 수 있으며, 진행 중인 사건이나 훈련 중에는 구매할 수 없다.

## v0.6 지역 해금

- 경계의 숲 다음 지역으로 달빛 능선을 추가한다.
- 달빛 능선은 레벨 2와 작은 랜턴을 모두 갖추면 이동할 수 있다.
- 지역별 사건 풀과 보상 범위가 다르며, 각 지역의 사건 순환은 별도로 기록한다.

## v0.7 지역 퀘스트와 보스

- 일반 사건의 조사 횟수와 성공 횟수를 채우면 해당 지역의 보스 사건이 열린다.
- 보스 성공 시 지역별 보스 격파가 저장되며, 일반 사건보다 높은 골드 보상을 얻는다.
- 보스 실패 시 격파 상태가 되지 않으며, 준비한 뒤 다시 도전할 수 있다.

## v0.8 운동 입력 어댑터

- 야외는 거리와 시간의 모의 신호로 페이스를 계산해 다음 사건에 사용한다.
- 실내는 동작 수 모의 신호를 받아 훈련 성공 시 소량의 경험치 보너스를 준다.
- 현재 입력은 테스트용 수동 신호이며, 추후 GPS·카메라·웨어러블 데이터로 동일한 어댑터를 교체한다.

## 자동 검증

- 상태 전이: 시작 전 보상 없음, 사건 중 중복 시작 불가, 해결 뒤에만 결과 반영.
- 경제: 1,000개의 20분 모의 플레이에서 기력 범위, 보상 상한, 성공률, 경험치 범위를 확인.
- 이 테스트는 게임 재미, 인터벌 안전성 또는 실제 플레이의 밸런스를 입증하지 않는다.
