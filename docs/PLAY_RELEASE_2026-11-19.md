# Motion RPG · S21 암밴드 실전 플레이 v1.0 (2026-11-19)
## 바로 시작
- 폴드6 Chrome/삼성 인터넷: https://secom3-tech.github.io/motion-rpg/preview.html?v=1.1
- S21 Chrome/삼성 인터넷: https://secom3-tech.github.io/motion-rpg/dumbbell.html?v=1.1
- S21을 팔꿈치 아래 전완부에 고정하고, 처음에는 가벼운 아령으로 동작을 시험한다.
1. 폴드6의 마을에서 숲 사냥 출발 → 연결 코드 만들기.
2. S21에서 6자리 코드 입력 → 게임 연결 → 센서 켜기 → 아래 자세 기록 → 위 자세 기록.
3. S21의 센서 수신 횟수, 각도 변화 및 컬 횟수를 확인한다. 한 번 완성된 아령 컬이 1회 입력이다.
4. 폴드6에서 설정 닫기 → 아령 사냥 시작. 카메라 자세 인식을 켜면 좌우 회피·몸 낮추기를 인식하며, 실패하면 화면 버튼 사용 가능.
5. 언제든 폴드6에서 마을 복귀 → 사냥 결과 → 마을로 돌아가기. 경험치/골드/제작재료/수집품은 기존 중복 방지 규칙으로 정산한다. 대장간에서 장비 제작/장착.

## 플레이 방식
- 캐릭터가 적을 자동 탐색·접근·락온하며, 근접 사거리 안은 검, 밖은 활로 전환한다.
- 처치 후 다음 몬스터가 나타난다. 정해진 운동 시간은 없으며, 스스로 운동을 멈추고 싶다면 마을 복귀 버튼을 누른다.
- 마을의 누적 처치 목표는 플레이 안내다. 새 XP/골드 보상을 추가하지 않았다.
- 대장간 제작 장비 16종의 썸네일을 통일된 그려진 장비 이미지로 제공하며, 나머지 보유 시작 장비는 이전 일러스트를 유지한다.
- 마을의 '레벨 1부터 새 모험 시작'은 **명시적으로 선택할 때만** 작동한다. 이때 현 브라우저의 기존 캐릭터와 사냥 기록을 로컬 백업한다.
- 스토리/비밀은 사전에 공개하지 않으며, 기존 GAME_RULES와 PRODUCT_VISION을 유지한다.

## 확인한 것과 남은 것
- GitHub Actions의 자동 코드·경제·전투 회귀 검사와 Pages 배포 결과를 확인했다.
- 실제 폴드6·S21 2기기의 아령 컬 정확도, 통신 지속성, 카메라 회피, 휴대전화 배터리/발열은 사용자 현장 시험이 필요하다. 이 버전은 **오늘 사용할 수 있는 첫 플레이 릴리스**이지 모든 콘텐츠와 실기기 QA가 완료된 상용 정식판이 아니다.
- 6자리 WebRTC 페어링에는 인터넷 연결 및 외부 PeerJS 시그널 서비스가 필요하다.
- 새 레벨 1 시작 시 백업은 해당 브라우저 안에 저장되므로 브라우저 데이터 삭제/다른 기기에서는 복원되지 않는다.
