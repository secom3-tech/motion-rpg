## 이번 수정 (기존 게임 규칙 변경 없음)
1. `src/frame-loop.mjs`: 프레임 예약을 `update/render` **이전**에 실행하고, 예외는 `update`/`render` 단계별로 기록해 한 번의 JS 오류가 영구 정지를 일으키지 않도록 보호.
2. `indoor.html`: 몬스터의 공격 경고/충돌 3D 이펙트를 분리 보호. 이펙트 도중 JS 오류가 나면 해당 세션의 특수 공격 이펙트만 비활성화하고 기본 전투/몬스터 3D/판정을 계속 진행.
3. 오류 발생 시 일시적인 화면 경고와 `localStorage['motion-rpg-last-frame-error-v1']` 진단 저장 (시점, update/render/attack-vfx, 메시지, 스택, 몬스터 및 공격 상황). 재발 시 오류 문구 화면을 캡처하면 원인 추적 가능.
4. `preview.html` 사냥 입장 링크 캐시 버전을 v0.53으로 갱신. 워치4 네이티브 연결 앱 APK/워치 입력 프로토콜은 건드리지 않음.
5. `tests/frame-recovery.mjs`: 렌더/업데이트 예외가 나도 다음 프레임이 예약되는지 자동 검증.
